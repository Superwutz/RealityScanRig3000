RealityScanRig3000

Firmware Installer

Flash your controller over USB directly from the browser. This is the official end-user installer maintained by Superwutz.

Install / Update

Connect your board via USB, then start flashing with one click.

  1. Select the correct serial device in the browser popup.
  2. Wait until flashing is complete (do not unplug USB).
  3. Open http://scanrig.local/ or your router-assigned IP.
If your board is not detected, use a USB data cable and close apps that lock the serial port.

Requirements

  • Desktop Chrome or Edge (Web Serial support required).
  • ESP32 board with stable USB power.
  • No serial monitor open while flashing.

Troubleshooting

  • "Failed to initialize": reconnect USB and retry.
  • "Manifest error": hard-refresh the page and run again.
  • No UI after flash: check Wi-Fi credentials in local secrets and reboot once.
